# Book Management System

A React-based Book Management System with CRUD functionality using MockAPI.

## Features

- View all books
- Add new books
- Edit existing books
- Delete books
- Search by title or author
- Filter by genre

## Tech Stack

- React
- React Router DOM
- Axios
- MockAPI
- Vite

## Setup Instructions

1. Clone repository

git clone https://github.com/Vaibhav-Sonawane/book-management-system.git

2. Install dependencies

npm install

3. Run project

npm run dev

## Build

npm run build
